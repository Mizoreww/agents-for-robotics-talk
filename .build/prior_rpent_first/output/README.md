# Agents for Robotics

## 当前版本：单文件 HTML + 中文讲稿

- **Agents_for_Robotics_Self_Contained.html**：26 页英文幻灯片，3 个细讲标杆，15 段视频，原始论文图，4 张章首流程图（第 5、12、17、23 页）。图片、视频、中英文字体、样式、脚本与中文讲稿全部内嵌。文件约 115 MB。
- **Speaker_Script_Revised.md**：中文逐页讲稿；论文名、模型名及技术术语保留英文。含建议时间、读图说明、播放提示和来源。与 HTML 内嵌讲稿一致；各章先用流程图导读，再展开案例，章末保留简短总结。

第一章以 Agent → 多种 Agent Tools 为导读，加入 RPent 原图及具体工具调用例子，简述 ROSA / ROS-MCP；IK / WAM 与已测接口分开解释。第四章为 Other Applications，包含结构设计和程序调试。仍然只细讲三个标杆。

只需移动 HTML 本身，无需 ZIP 或配套文件夹。建议用桌面 Chrome / Edge 等现代浏览器打开；手机文件管理器内置预览未必支持大 HTML 或 H.264 播放。

## 操作

- Previous / Next 或左右方向键翻页；页码菜单可直接跳转。
- Play videos 播放当前页；Pause 暂停；Restart 从头开始。也可使用单个视频自身的播放控件。
- Speaker script 显示当前页中文讲稿。Full script 切到整篇，Current slide 返回逐页。
- 点击论文图查看大图，Close figure 或 Esc 关闭。
- Fullscreen / F 打开更大的演讲视图。浏览器允许时同时请求原生全屏；内嵌预览器不支持时保留专注视图。Exit view 返回。
- N 切换讲稿，Space 播放/暂停。键盘焦点在页码菜单时，保留菜单自身的键盘行为。

60 分钟为包含视频、读图和短互动的建议安排，实际时长请以彩排为准。资料截点为 2026-09-10。社媒 demo 不等于重复实验；关键分母、retry 及人工准备条件见讲稿。
