# 静态机器人说明 v3：四场景独立上下文结果

本轮只有转向 return 提高；站立、前进、侧移下降。四场景平均 return 从 v2 的
4.025979 降至 2.955868（-26.58%），完整 horizon 仍为 3/4，但前进变为提前停止，
转向变为完成。每场仅一次推理样本，不能把这些差异当成静态几何信息的平均因果效应。

## 实验条件与记录

批次 `astra-robot-spec-v3-20260910T093043Z`，2026-09-10 17:30:43—17:42:26
（香港），总 wall time 约 11 分 43 秒。四个场景各自独立进程、policy 和 history。
每场各运行一次，没有挑选性重试，也没有拼接不同批次的最佳结果。

控制代码对应 [15407a4](https://github.com/guajun/gpt-dog-eval/commit/15407a4)，
远端工作目录仍是 `43c607a-dirty`，实际源代码 SHA-256 写入 manifest；本地与远端
agent、robot_spec、embodiment 和启动脚本哈希逐一核验相同。

新增输入为实际 MuJoCo 模型导出的静态描述：13 刚体、12 关节的父子关系、原点/轴、
质量/质心/惯量、默认关节角、执行器和碰撞配置；系统提示共 14,327 字符。静态说明
SHA-256 为 `9fe71127ced2957c048a9e454a716360d2e0f3d4f334dd72696812cbb4449cf9`，
四场一致。模型源 XML、静态 JSON 和完整系统提示分别留在每场的 `model-sources/`、
`robot-spec.json`、`system-prompt.txt`；模型实际收到的是说明文字和 compact JSON，
没有重复加入原始 XML/mesh。

保留 Astra/xhigh、250 步（5 秒）、每场 60 次调用、最多 15 步和 4 keyframes/chunk、
每步动作变化上限 0.1、50 Hz 控制、250 Hz 物理步进。eval seed=0，epoch=0，
scene init seeds=11/22/33/44，噪声和扰动关闭，请求 timeout=180 秒。
工具、动作反馈、reward、物理和动态观测均沿用 v2；没有接触输入、FK/IK 工具、
示范或低层稳定器。静态描述包含当前 feetonly 碰撞范围，实际仿真未切换模型。

按用户要求，新图表只比较 Zero、原生 ONNX-PPO、Astra v2、本轮 Astra + robot spec。
v1 及其他 pre-v2 Astra 结果不参与；历史日志和旧报告保留。

## 执行与上下文核验

- 143 次有效动作请求前的 `last_applied_action` 与实际末动作一致；初始调用预算

- 866 行 telemetry 连续，动作与反馈一致；原始 actor 的上一动作字段保留一帧滞后。

## 丢分与动作行为

**站立。** `stand_still` 相对 v2 多扣 1.632，pose 少得 0.309，XY 跟踪少得
0.215，是主要退步来源。早期有明显速度和姿态瞬态，共 44 个零 reward 步；最终
倾角虽仅 0.338°，全程仍积累了较多相对默认关节角的偏移。负 reward 截零带来的
调整比 v2 多 0.554，已经抵消部分原始成本，不能将它解释为额外行为奖励。

**前进。** 共同前 116 步，本轮 return=1.175293，v2=1.677736，差 -0.502443；
v2 后续 134 步还取得 3.049534，构成全程差距的约 86%。在共同时间内，XY 跟踪
奖励反而略高 0.050，主要原始退步为 orientation -0.586、横滚/俯仰角速度成本
-0.459、feet_clearance -0.324、yaw 跟踪 -0.195。

step 80 倾角约 3.2°，90 为 13.4°，100 为 17.5°，110 达 45.3°；此时 pitch
rate 约 5.69 rad/s。模型连续尝试落脚、恢复四足支撑、调整前后腿长度和紧急俯仰
恢复，但 step 115 倾角仍到 74.8°，随后 give_up，116 结束时 79.5°。没有达到
上游 >90° 的物理 fall 阈值。可以确认恢复控制未奏效；模型关于“无法恢复”的
文字说明不构成物理不可恢复的证明。此轮没有额外回放接触状态，因此不凭这些
notes 断言某只脚实际着地或离地。

**侧移。** 同为 250 步，XY 跟踪少得 0.790、orientation 多扣 0.395、yaw 跟踪
少得 0.271。平均左向速度由 v2 的 0.144 降到 0.064 m/s，目标为 0.3；轨迹有
明显的左右反复。平均 yaw 由 0.316 降到 0.022 rad/s，但 yaw RMSE 从 0.759
增到 0.880，说明正负转动相抵掩盖了振荡，不能只看有符号均值。

**转向。** 完成 250 步，最大倾角 29.59°，最后 0.461°。相对 v2 的总收益
+2.849558 中，共同前 107 步只增加 0.214476，新增 143 步贡献 2.635082。
共同时间内 orientation 原始贡献改善 1.280，但 v2 的负 reward 截零已抵消
不少成本，所以实际 prefix return 的增幅更小。完成时段明显改善，但全程平均
yaw 仅 0.081 rad/s（目标 0.5），yaw RMSE 仍为 0.865；存在较大的正反向角速度
振荡，并非稳定达到转向指令。

## 后续 policy 复查：落脚、站姿与反馈频率

仅分析既有 v2/v3 数据，并离线回放 v3 forward 原始 116 个动作，没有付费推理或
控制修改。脚本 `scripts/review_robot_spec_policy.py` 输出 `comparison/policy-review.json`
和 `forward-diagnostic-replay.npz`。逐步观测误差小于 1e-7，reward 误差小于 1e-9，
总 return 误差为 0。首次诊断脚本在首个物理步后因 JAX 不接受 list 索引而退出，
改为先转换 NumPy 后完成回放；这是离线分析代码错误，原始评测结果没有变化。

站立的稳定末段（151—250 步），按实际关节角进行 FK，机身坐标系左右足中心的
平均横向间距由 v2 的 0.2195 m 增至 v3 的 0.3135 m。v3 首个动作 note 明确提出
加宽站姿，后续多次保持 broad stance；稳定后髋关节 residual 约为右 -0.3、左 +0.3。
最后 100 步的关节偏离量 `mean(sum(abs(q-nominal)))` 由 0.8177 增至 1.0066 rad，
约增 23%；该时段 return 从 2.2601 降至 1.7079。前 100 步也从 1.6431 降至
0.4729，因此退步同时包含较大的起始瞬态和稳定后的姿态偏置。

当前提示只要求平衡、速度跟踪和平滑动作，未向模型提供 stand_still、pose 等评分
定义及权重。加宽站姿这一选择与“追求稳态”可以一致，却受到当前默认姿态偏离
惩罚。应将“评分目标说明不完整”和“闭环控制失稳”区分；如后续提供静态评分
定义，需要记作新的评测条件，而不能混入本轮结果。

侧移全程 vy<0 的比例由 v2 的 6.4% 增至 v3 的 41.6%；使用 vy<-0.02 m/s
排除近零噪声后，仍为 5.2% → 38.8%。本轮的主问题是周期性往返抵消位移，
并非只有恒定欠速。转向有 47.2% 控制步的 yaw<0，平均正向 yaw 0.081 rad/s
不能代表稳定持续转向。完成时段增多与跟踪质量应分开报告。

| 场景 | v2 chunk 中位步数 | v3 chunk 中位步数 | v2 → v3 平均运动反馈频率 |
|---|---:|---:|---|
| stand | 6 | 8 | 6.8 → 5.8 Hz |
| forward | 7 | 6 | 7.0 → 8.26 Hz |
| left | 7 | 5 | 7.8 → 9.4 Hz |
| turn | 6 | 5 | 7.55 → 9.4 Hz |

该频率按运动/hold chunk 数除以其模拟时长计算，去掉工具校验失败和 give_up 的
单帧 stop。本轮三个运动场景反馈普遍更频繁，所以不能将退步解释为 v3 使用了
更长的 chunk；更短 chunk 的单独收益仍需控制变量实验确认。

前进的离线接触检查（顺序 FR/FL/RR/RL）：

| 物理步 | 接触 | 倾角 | 观察 |
|---|---|---:|---|
| 80 | 1/0/1/1 | 3.21° | FL 抬起，其余脚接触 |
| 85 | 0/0/0/1 | 7.87° | 仅 RL 接触，换相出现短暂单脚接触 |
| 95 | 1/1/1/0 | 15.58° | RL 离地 |
| 105 | 1/0/0/0 | 19.80° | 仅 FR 接触 |
| 106—111 | 始终 1/1/0/0 | 111 时 51.66° | 两只后脚没有落地，前脚保持接触 |
| 115 | 0/1/0/0 | 74.81° | 模型随后调用 give_up |
| 116 | 0/1/0/0 | 79.53° | stop 单帧后终止 |

step 111 时两只后足球中心离地高度约 0.285/0.170 m。这个轨迹支持“前脚接触、
身体继续向前俯倒、后脚抬高，恢复动作未建立预期支撑”的诊断。本段没有四脚
全部离地的时刻，与上一轮转向的失稳过程不同。接触布尔量不等于支撑力大小；
上述数据不能唯一证明某一个电机目标就是初始根因。当前足部接触信息仅用于
离线分析，没有反馈给 Astra 或改动 ONNX 的输入。

新增参数并不保证它据此进行了准确的运动学或动力学计算；公开日志保留动作及
notes，未提供可据以验证内部计算过程的证据。可以确认的是此次采取的站姿、
往返运动和恢复动作及其物理结果。要判断新增静态说明的平均影响，仍需重复样本。
